Project details

A quick overview of this Digital Library project.

🎯

Project purpose

Organize a library's books and members, track borrowing and returns, and make collection information easy to review.

🧰

Main features

Account registration and login, book search and management, member records, separate issue and return workflows, and library reports.

💻

Technology

Built with HTML, CSS, and JavaScript. Library records are saved in this browser using local storage.
