ABOUT THIS PROJECT

A simpler way to manage a library

Digital Library is a browser-based library management project for organizing books and members, tracking loans, and viewing useful collection reports.

Project purpose

The project brings common library tasks together in one clear interface. Library staff can maintain the collection, keep member details up to date, and follow each book from issue to return.

📚

Book collection

Add, edit, delete, and search books by title, author, or category.

👥

Member records

Create and maintain member profiles with contact information.

🔄

Book circulation

Issue available books, set due dates, and record returns separately.

📊

Library reports

Review book, member, issue, return, and availability totals.

How it works

  1. Create an account and sign in to the dashboard.
  2. Add books and members to the library records.
  3. Issue available books with a due date.
  4. Record returns and review updated reports.

Built with

  • HTML for page structure and accessible forms
  • CSS for responsive layouts and visual design
  • JavaScript for interactions and library workflows
  • Browser local storage for saving project records

This learning project stores its records in the browser's local storage. Data is kept in the current browser and is not shared between devices.
